# ToolNest website starter

## Included
- Responsive homepage
- 6 working browser-based tools: image compressor, word counter, percentage calculator, age calculator, JSON formatter and case converter
- About, Privacy Policy, Terms and Contact pages
- SEO title/description metadata, robots.txt and sitemap.xml
- Clearly marked ad placement placeholder

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a public repository named `toolnest`.
3. Upload all files in this folder to the repository root (not the ZIP itself).
4. Open repository Settings -> Pages.
5. Select Deploy from a branch, choose `main` and `/ (root)`, then Save.
6. GitHub will provide a public website address.

## Before launch
- Replace `YOUR-DOMAIN.com` in index.html, robots.txt and sitemap.xml with your actual domain/Pages URL.
- Replace `YOUR-EMAIL@example.com` in contact.html and privacy.html.
- Test every tool on mobile and desktop.
- Add genuinely useful, original explanatory content and a clear contact/about/privacy experience.
- Do not add AdSense code until the site is approved. Apply through your own Google account and follow current AdSense policies.
- A domain is optional at first, but a custom domain may improve branding.

## Important
This starter does not guarantee Google indexing, AdSense approval, traffic or revenue. Do not click your own ads, buy fake traffic, or encourage visitors to click ads. Check current Google publisher policies and applicable privacy/consent requirements before monetizing.
